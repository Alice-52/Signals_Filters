# Лабораторная работа: Анализ Фурье аналоговых сигналов

## Описание
В данной лабораторной работе исследуется финитный сигнал некоторого типа:

`x(t) = (4 - 0.1|t-3|) * cos(4πt) на интервале t∈[1,9], вне интервала x(t)=0`

Проводится анализ принадлежности сигнала функциональным пространствам, его спектральный анализ двумя способами (прямое вычисление преобразования Фурье и быстрое преобразование Фурье), а также сравнение эффективности методов.

## Цели работы
1. Изучить свойства сигнала и его преобразования Фурье.
2. Реализовать прямое численное интегрирование для получения спектра (АЧХ).
3. Использовать БПФ (с zero-padding) для ускорения вычислений.
4. Сравнить точность и производительность двух подходов.

## Файлы
- `lab1.ipynb` / `lab1.py` – основной код с реализацией и графиками.
- `README.md` – краткое описание (данный файл).

## Результаты
- Сигнал финитен, кусочно-непрерывен, принадлежит `L1` и `L2`, но не классу Шварца.
- Прямое ПФ при грубой дискретизации (N=50) даёт искажённый спектр из-за эффекта наложения; при мелкой (N=500) – близок к истинному, но требует больших вычислительных затрат (~1e6 операций).
- БПФ с N_fft=2048 позволяет получить гладкий спектр за ~2.2e4 операций (ускорение в 45 раз).
- Основной пик спектра соответствует частоте 2 Гц, ширина пика обусловлена ограниченностью сигнала во времени.
